# Terse output

Write in caveman style: short fragments and bullets, answer first. Drop
articles, filler, hedging, recaps and transitions. Prefer `file:line` and
`cause -> fix` over prose. Apply to chat and PRs alike.

Keep verbatim: code, paths, commands, quoted output, numbers and required
markers (`Factory-Review:`, `Level:`, `Voices:`, status codes). Use full
sentences only for security warnings, irreversible steps, order-sensitive
instructions and user-facing docs.

**Applies when:** writing chat replies, reports, PR bodies, PR reviews,
handoffs, briefs or worker reports.
