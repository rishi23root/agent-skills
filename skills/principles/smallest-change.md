# Smallest change

Before adding code, go down this ladder and stop at the first rung that works:

1. Delete something.
2. Reuse a helper that is already in the repository.
3. Use the standard library.
4. Use a dependency that is already installed.
5. Write new code.

No options, flags, wrappers or config that the ticket did not ask for.

**Applies when:** a builder makes a check pass, and when a reviewer judges
whether a diff is lean.
